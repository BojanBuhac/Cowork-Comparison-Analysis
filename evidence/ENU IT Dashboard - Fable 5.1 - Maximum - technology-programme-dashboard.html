Microsoft Azure / Foundry

Assistants API retired 26 Aug 2026 — Foundry Agent Service is the successor

Microsoft's guidance confirms the Azure OpenAI Assistants API retired on 26 August 2026, with Foundry Agent Service (built on the Responses API, adding MCP tool calling, background mode and durable streams) as the migration target; a migration tool is available. Inference-only workloads can use the Responses API.

Relevance: the retirement notice landed in Corey's mailbox for subscription ME-M365CPI81743996-bobuhac-1; no migration evidence exists internally (R5).
Sources: W1 W2 S3
Microsoft 365

Microsoft Agent 365 generally available since 1 May 2026

Agent 365 is licensed per user (E5 recommended as prerequisite) and provides a centralised agent registry, lifecycle/access governance through the Microsoft 365 admin center, Entra and Purview, and Defender-based protection. Microsoft 365 E7 is also now GA per the Microsoft 365 roadmap page.

Relevance: AI Agent Central v3 advertises Agent 365 integration; the failing "Collect A365 Agents" flows are the bridge between the two (R4).
Sources: W3 W4 S17
Microsoft 365 Copilot connectors

Self-serve sync connectors for Jira Cloud and Confluence Cloud — preview now, GA October 2026

Users authenticate with their own identity and only their accessible content (work items or pages modified in the last 90 days) is indexed; a seven-day admin review period applies before a connector becomes visible. Microsoft ships three ServiceNow connectors (Tickets, Knowledge, Catalog) and federated MCP-based connectors since March 2026.

Relevance: offers a fallback for the failing tenant-level Jira connection (R7) and context for the ServiceNow remediation (R3).
Sources: W5 W6 W8
