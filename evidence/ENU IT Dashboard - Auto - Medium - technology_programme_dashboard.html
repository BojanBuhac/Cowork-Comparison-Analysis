External signals — vendor roadmaps & market context

Azure OpenAI Assistants API retired 26 August 2026

Microsoft's guidance is that applications relying on the Assistants API had to be migrated before 26 August 2026, after which it is no longer available; the supported replacements are the Microsoft Foundry Agent Service and the OpenAI Responses API. Foundry Agent Service (classic) carries its own, later retirement date. Programme relevance: directly affects any S2P or AI Agent Central workload built on the older surface.
