Market benchmark

Agent embedding is becoming table stakes

Gartner projects that 40% of enterprise applications will embed task-specific AI agents by the end of 2026, up from under 5% at the start of 2025 — a useful benchmark for how aggressively the ERP award should weight agentic capability.

PlanAxion, “AI Agents in ERP Systems: What Changes in 2026”
planaxion.com/en-ca/articles/ai-agents-erp-2026

Vendor roadmap

Microsoft 2026 Release Wave 1

Microsoft published its 2026 release wave 1 plans for Dynamics 365, Power Platform and Copilot Studio (18 March 2026), centred on AI agents and automation — directly relevant to the Power Platform layer currently carrying the failing flows.

Microsoft Dynamics 365 Blog
microsoft.com — 2026 release wave 1 plans

Competitive landscape

ERP agent architectures are diverging

Reporting on the ERP agent market describes SAP, Oracle and Microsoft racing to embed autonomous agents into the core ERP layer with materially different architectures — SAP Joule, Oracle Fusion AI Agents and Copilot for Dynamics 365 — which matters for lock-in and integration effort in the RFP scoring.

AgentMarketCap, “The $35B ERP Agent War” (11 April 2026)
agentmarketcap.ai — ERP agent war

Vendor moves

Consolidation and volume releases

Coverage notes SAP merging Joule with Microsoft Copilot and Oracle shipping 22 agent applications in a single wave — a signal that shortlisted mid-market ERP vendors should be tested on their agent roadmap depth, not just current functionality.

PlanAxion, “AI Agents in ERP Systems: What Changes in 2026”; erpimplementation.eu, “Agentic AI ERP 2026”
